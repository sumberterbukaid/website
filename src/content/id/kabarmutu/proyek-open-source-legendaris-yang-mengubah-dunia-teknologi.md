Jika internet modern tiba-tiba menghapus semua kode open source, yang tersisa hanyalah halaman kosong. Tidak ada website, tidak ada Android, tidak ada AI, tidak ada animasi film. Dunia digital akan padam.

Kita sering memakai open source setiap hari tanpa menyadarinya. Artikel ini akan merayakan tujuh proyek legendaris yang bukan sekadar software gratis, tapi proyek yang secara fundamental mengubah arah sejarah teknologi — dan semuanya bisa kamu periksa source code-nya hari ini.

## 1. Linux Kernel (1991) — Jantung yang menolak mati

**Pencipta:** Linus Torvalds

**Lisensi:** GPL v2

**Kenapa legendaris:** Ia adalah bukti bahwa ribuan orang asing di internet bisa membangun sesuatu yang lebih baik daripada perusahaan bernilai miliaran dolar.

Sebelum Linux, sistem operasi adalah barang mahal yang terkunci. UNIX mahal, Windows tertutup. Linus, mahasiswa 21 tahun dari Finlandia, hanya ingin membuat hobi yang "tidak akan besar dan profesional seperti GNU".

Hari ini, Linux menjalankan 96% dari 1 juta server teratas dunia, 100% dari 500 superkomputer tercepat di dunia, sistem operasi Android yang ada di 3 miliar perangkat, router WiFi di rumahmu, kulkas pintar, hingga sistem kontrol di Stasiun Luar Angkasa Internasional (ISS).

Kehebatannya bukan hanya pada kodenya, tapi pada model pengelolaannya. Linus tidak mengelola sendirian. Ia memiliki ratusan maintainer tepercaya di seluruh dunia dengan hierarki yang sangat meritokratis. Setiap baris kode yang masuk harus melalui review berlapis. Inilah yang membuat Linux menjadi proyek kolaborasi terbesar dalam sejarah manusia.

Tanpa Linux, tidak ada cloud, tidak ada Google, tidak ada Gojek.

## 2. Apache HTTP Server (1995) — Penjaga gerbang web

**Pencipta:** Robert McCool dan komunitas NCSA httpd

**Lisensi:** Apache 2.0

**Kenapa legendaris:** Ia adalah software yang membuat World Wide Web bisa diakses semua orang.

Pada 1995, web masih bayi. Server web yang ada saat itu, NCSA httpd, sudah tidak lagi dikembangkan. Sekelompok developer di mailing list membuat patch demi patch untuk memperbaikinya. Mereka menyebut diri mereka "a patchy server" — yang kemudian menjadi Apache.

Apache dengan cepat menjadi server web nomor satu di dunia dan mempertahankan posisi itu selama lebih dari dua dekade. Pada puncaknya, ia melayani lebih dari 70% website di internet. Bahkan ketika posisinya kini digeser oleh Nginx (yang juga open source), fondasi yang ia letakkan — konsep virtual host, module, dan .htaccess — masih menjadi standar.

Lebih dari sekadar server, Apache melahirkan Apache Software Foundation, inkubator bagi ratusan proyek legendaris lain seperti Hadoop, Spark, dan Kafka yang menjadi tulang punggung big data.

## 3. Mozilla Firefox & Chromium (1998 / 2008) — Perang untuk web yang terbuka

**Pencipta:** Netscape (Firefox) & Google (Chromium)

**Lisensi:** MPL / BSD

**Kenapa legendaris:** Mereka menyelamatkan internet dari monopoli total.

Pada akhir 90-an, Internet Explorer dari Microsoft menguasai 95% pasar browser. Microsoft hampir berhasil mengunci web dengan teknologi proprietary ActiveX. Web yang terbuka hampir mati.

Netscape, dalam langkah putus asa yang jenius, pada 1998 membuka source code browser mereka dan melahirkan Mozilla. Dari abu Netscape lahirlah Firefox pada 2002, yang dengan semangat komunitas berhasil merebut kembali pasar dan memaksa web kembali ke standar terbuka.

Kisah berulang pada 2008. Google merilis Chrome, tapi dengan langkah yang lebih cerdas: mereka merilis engine-nya sebagai proyek open source bernama Chromium. Hari ini, hampir semua browser modern — Edge, Opera, Brave, Vivaldi, bahkan Samsung Internet — dibangun di atas Chromium open source. Ironisnya, dominasi Chromium kini menjadi tantangan baru bagi keterbukaan web, tapi faktanya engine tersebut tetap terbuka untuk diaudit siapa saja.

Tanpa Firefox dan Chromium, kita mungkin masih harus menulis website khusus untuk satu browser saja.

## 4. WordPress (2003) — Demokrasi penerbitan

**Pencipta:** Matt Mullenweg & Mike Little (fork dari b2/cafelog)

**Lisensi:** GPL v2

**Kenapa legendaris:** Ia memberikan kekuatan penerbitan yang dulu hanya dimiliki korporat media kepada seorang blogger di Surabaya.

WordPress dimulai sebagai fork sederhana dari proyek yang sudah ditinggalkan. Tujuannya sederhana: membuat platform blogging yang elegan dan mudah dipakai.

Hari ini, WordPress menjalankan lebih dari 43% dari seluruh website di internet. Bukan hanya blog pribadi, tapi website Gedung Putih (whitehouse.gov), The New Yorker, BBC America, dan jutaan UMKM di Indonesia. Ekonomi di sekitarnya — tema, plugin, hosting — bernilai puluhan miliar dolar.

Kekuatan WordPress bukan pada teknologinya yang paling canggih, tapi pada filosofinya: semua orang berhak punya suara di internet tanpa harus bisa coding. Dan karena berlisensi GPL, tidak ada satu perusahaan pun yang bisa mengklaim kepemilikan atas 43% web tersebut.

## 5. Android Open Source Project - AOSP (2008) — Open source di saku miliaran orang

**Pencipta:** Google & Open Handset Alliance

**Lisensi:** Apache 2.0 / GPL v2 (kernel)

**Kenapa legendaris:** Ia membawa open source dari ruang server ke tangan nenekmu.

Sebelum Android, sistem operasi ponsel adalah benteng tertutup: Symbian, BlackBerry OS, iOS. Google mengambil kernel Linux, membangun sistem operasi di atasnya, dan merilisnya sebagai Android Open Source Project.

Keputusan menggunakan lisensi Apache 2.0 (yang permisif) membuat produsen seperti Samsung, Xiaomi, dan Oppo bisa memodifikasi Android secara bebas tanpa harus membuka semua modifikasi mereka. Inilah yang membuat adopsinya meledak.

AOSP memungkinkan lahirnya ekosistem custom ROM, memungkinkan developer di Indonesia membuat ROM untuk kebutuhan lokal, dan menjadi dasar bagi proyek-proyek penting lain seperti LineageOS dan bahkan sistem operasi untuk TV, jam, dan mobil.

Tanpa AOSP, smartphone mungkin masih menjadi barang mewah eksklusif.

## 6. Git (2005) — Bahasa yang digunakan programmer untuk berkolaborasi

**Pencipta:** Linus Torvalds (lagi)

**Lisensi:** GPL v2

**Kenapa legendaris:** Ia adalah alat yang membuat semua proyek open source lainnya bisa ada dengan skala seperti sekarang.

Ironisnya, Git lahir karena konflik. Linus membutuhkan sistem version control untuk mengelola kernel Linux setelah BitKeeper — sistem proprietary yang mereka pakai — menarik lisensi gratisnya. Dalam dua minggu, Linus menulis sendiri sistem version control terdistribusi yang jauh lebih cepat dan lebih kuat daripada apa pun yang ada.

Git mengubah cara manusia berkolaborasi dalam menulis kode. Konsep commit, branch, merge, dan pull request menjadi bahasa universal developer. Tanpa Git, tidak akan ada GitHub, tidak akan ada GitLab, dan model kontribusi open source modern tidak akan pernah seefisien sekarang.

Jika Linux adalah jantungnya, Git adalah sistem sarafnya.

## 7. Blender (1994/2002) — Bukti open source bisa mengalahkan Hollywood

**Pencipta:** Ton Roosendaal

**Lisensi:** GPL v2

**Kenapa legendaris:** Ia adalah kisah kebangkitan paling dramatis dan bukti bahwa open source bisa menang di ranah kreatif.

Blender awalnya adalah software animasi 3D komersial dari perusahaan Belanda bernama Not a Number (NaN) yang bangkrut pada 2002. Software-nya hampir hilang selamanya.

Ton Roosendaal, pendirinya, melakukan kampanye "Free Blender" — mengumpulkan donasi 100.000 Euro dari komunitas untuk membeli source code Blender dari investor dan merilisnya sebagai open source.

Dari software yang hampir mati, Blender tumbuh menjadi monster. Hari ini, Blender dipakai oleh Ubisoft untuk membuat game, oleh Netflix untuk produksi film, oleh NASA untuk visualisasi, dan oleh ribuan kreator YouTube di Indonesia. Fitur-fiturnya kini menyaingi bahkan melampaui software proprietary seharga ribuan dolar seperti Maya dan 3ds Max.

Blender membuktikan bahwa model open source tidak hanya cocok untuk infrastruktur, tapi juga untuk alat kreativitas tingkat tinggi.

## Benang merahnya

Jika kamu perhatikan, ketujuh proyek ini memiliki pola yang sama:

1.  Mereka lahir dari kebutuhan pribadi, bukan dari riset pasar.

2.  Mereka hampir mati atau diremehkan di awal.

3.  Mereka menang karena komunitas, bukan karena modal.

Mereka mengingatkan kita pada angka yang ada di file contoh pertamamu: **663.262 dataset** di data.go.id yang terus dikurasi. Nilai sebuah ekosistem terbuka tidak terletak pada jumlahnya yang besar, tapi pada apakah satu orang di Surabaya bisa mengambil satu bagian kecil darinya, memperbaikinya, dan membagikannya kembali sehingga menjadi lebih baik untuk semua.

Itulah warisan sejati dari proyek-proyek legendaris ini.
